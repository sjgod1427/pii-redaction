    How it decides

    1. 1
      Validator-backed patterns

      Emails, phones, cards (Luhn), IPs (octet-checked), PAN, CIN, GSTIN, Aadhaar, IFSC, DOB, addresses. A 16-digit number is only a card if it passes Luhn.

    2. 2
      A document-level gazetteer

      Pass 1 reads the whole file and learns who and what it talks about. Pass 2 matches that lexicon everywhere — so a name recognised once, in one good context, is redacted on every page.

    3. 3
      spaCy NER, filtered

      Used only as a candidate generator. Raw model output never reaches the document — it passes through the same document-derived filters, including a check that counts which words appear in lower case in ordinary prose.

    4. 4
      Places, and pictures

      Localities are harvested from the document's own addresses, then redacted in narrative prose — a set of plant towns identifies a company as surely as its letterhead. Images are OCR'd, face- and barcode-checked, and replaced whole.

    Deterministic: same input and seed produce byte-identical output. Built for the Scaler AI Labs assignment.
